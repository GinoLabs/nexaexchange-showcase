# About this repository

This is the public-facing showcase for NexaExchange.

NexaExchange is currently a **simulated exchange engineering project**.

Use this repository for:
- sanitized architecture
- simulator milestones
- public roadmap
- non-sensitive screenshots
- documentation
- collaboration and sponsorship

Do not use it for:
- private operational source
- credentials or environment files
- AWS or SSH secrets
- customer data
- internal incident evidence
- real-money deposit, withdrawal, or custody claims

The private operational/source repository remains separate.
