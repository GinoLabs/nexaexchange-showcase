# Public Release Checklist

Run this checklist before adding any new file, screenshot, diagram, demo, or document to this public repository.

## Text / code
- [ ] No `.env` file or secret value
- [ ] No AWS credential or account-sensitive value
- [ ] No SSH private key
- [ ] No database URL or password
- [ ] No API key or session token
- [ ] No internal incident evidence
- [ ] No customer or personal data
- [ ] No wholesale copy of private operational backend source

## Images / video
- [ ] No secret, token, password, QR code, or private key visible
- [ ] No browser address bar exposing sensitive URLs or query parameters
- [ ] No private AWS / infrastructure identifiers
- [ ] No internal incident details
- [ ] Simulator-only positioning remains clear

## Safety boundary
- [ ] No language implying real deposits or withdrawals are available
- [ ] No language implying real-money trading is live
- [ ] No language implying customer custody is active
- [ ] No claim that NexaExchange is a licensed exchange unless that becomes formally true and is independently verified

## Repository
- [ ] README still states simulator-only scope
- [ ] SECURITY.md remains present
- [ ] CONTRIBUTING.md remains present
- [ ] Private operational/source repository remains private

If there is any doubt, keep the material private until it is reviewed.
