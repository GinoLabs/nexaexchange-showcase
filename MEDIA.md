# Public Media Register

This register is the intake point for media intended for the public NexaExchange showcase.

## Current approved media

No simulator screenshots or videos are currently registered here as approved public showcase media.

## Before adding any screenshot or video

Confirm all of the following:

- no AWS credentials or account-sensitive values
- no SSH material
- no database URL or password
- no API key, session token, cookie, QR secret, or private key
- no customer or personal data
- no internal incident evidence
- no private infrastructure hostname or identifier unless intentionally public
- no browser address bar exposing a sensitive query string
- simulator-only positioning remains clear
- no visual claim that real deposits, withdrawals, custody, or real-money trading are live

## Recommended public media

Safe candidates may include:
- simulator trading dashboard
- order book and trade-history views using simulated balances
- sanitized architecture diagrams
- non-sensitive admin / monitoring concepts
- milestone or roadmap graphics

Each file should be added to this register with its purpose and public-review status before publication.
