# Contributing

NexaExchange is currently a **simulated exchange engineering project**.

The public repository is intended for documentation, portfolio material, architecture discussion, and safe collaboration. The private operational/source repository remains separate.

## Good contributions

Examples:
- documentation corrections
- simulator UX ideas
- accessibility suggestions
- testing ideas
- architecture feedback
- non-sensitive operational-readiness suggestions

## Do not submit

Do not include:
- real-money deposit or withdrawal code
- custody or wallet secrets
- copied private backend source
- .env files
- AWS credentials
- SSH keys
- database URLs
- passwords or tokens
- customer data
- internal incident material

## Safety boundary

Contributions must preserve the simulator-only boundary unless a separate legal, compliance, security, and operational program explicitly changes project scope.

## Security reports

Do not use public issues for vulnerability details. Follow SECURITY.md.
