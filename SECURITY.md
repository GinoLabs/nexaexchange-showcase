# Security

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a suspected security vulnerability.

Use the security contact documented by the project owner rather than posting exploit details publicly.

A report should include:
- affected simulator component
- concise impact description
- safe reproduction steps
- screenshots or logs only when they contain no secrets, tokens, personal data, or private infrastructure details

Never publish:
- AWS credentials
- SSH private keys
- database credentials
- API keys
- session tokens
- environment files
- internal incident evidence
- personal or customer data

## Scope

This public repository is a sanitized showcase for a simulated exchange engineering project. It is **not** a real-money exchange and does not accept real customer assets.

The private operational/source repository remains separate.

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.
